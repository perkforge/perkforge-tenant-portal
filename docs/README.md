# PerkForge household portal tenant

Inactive Helm/Fleet application definitions. Application source/image build lives
in perkforge-portal; platform foundations and security controls live in
perkforge-platform. See architecture.md for ownership and operations.md for offline
validation and approval gates. The chart renders nothing by default.

Root README/main bootstrap is reserved for the repository owner. This feature work
must be based onto that owner-created main before opening its draft PR.
